> 本教程基于腾讯云的Ubuntu 18.04 64位

<!--more-->

## 安装Node.js

``` Bash
curl -sL https://deb.nodesource.com/setup_12.x | sudo -E bash -
sudo apt-get install nodejs
```

安装完成后输入

``` Bash
node -v
```

若能提示版本则安装成功

## 更换国内源

```
npm config set registry https://registry.npm.taobao.org
npm config get registry
```

如果更换了国内源则不用安装 `cnpm`

## 安装cnpm

``` Bash
sudo npm install -g cnpm --registry=https://registry.npm.taobao.org
```

## 安装hexo

``` Bash
sudo cnpm install -g hexo
```

## 安装Git

有些系统已经预装，可先用`git --version`确认

``` Bash
sudo add-apt-repository ppa:git-core/ppa
sudo apt-get update
sudo apt-get install git
```

安装完成后输入

``` Bash
git --version
```

若能提示版本则安装成功

## 初始化hexo

``` Bash
mkdir hexo
cd hexo
hexo init
cnpm install hexo --save # 编译工具
cnpm install hexo-deployer-git --save # 安装自动部署发布工具
```

## 本地编译预览

``` Bash
hexo clean && hexo g && hexo s
```

Ubuntu 14可能出现没有`hexo s`命令

这时需执行

``` Bash
sudo cnpm install hexo-server --save
```

然后用`hexo clean && hexo g && hexo server`命令

打开`127.0.0.1:4000`即可访问网页

## 编译发布

在hexo目录下的`_config.yml`最下面添加

``` YAML
deploy:
  type: git
  repo: https://gitee.com/jupitersh/jupitersh.git
  branch: master
```

> 请将`repo`中的地址改为你码云的地址

### Git 全局设置:

发布前请先全局设置Git

``` Bash
git config --global user.name "辣椒小皇纸"
git config --global user.email "arxhd.love@qq.com"
```

> 请将`user.name`和`user.email`的内容执行替换成您的码云用户名和邮箱

**发布代码**

``` Bash
hexo clean && hexo g && hexo d # 发布博客
```

需输入码云的**账号**和**密码**
